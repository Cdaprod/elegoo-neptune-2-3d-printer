    ⚠
    Physical completion is reported only when evidence existsA transport acknowledgment is a controller reply, not a position measurement. Cancellation is not an emergency stop.
    
  
    Arm Operator Mode
    Uses your existing dashboard sign-in; no separate control credential is needed. Operator Mode stays armed until you disarm it or the service restarts. Each action still requires an explicit confirmation and fresh safety checks.
    
  
    Read-only position query
    This sends exactly one M114 and reads the firmware's reported position. It does not move or home axes, but support on this firmware is still unverified.
    
  
    Upload G-code to printer SD
    This writes one file to the printer over its MKS WiFi HTTP endpoint. The installed firmware’s upload support is not verified. Do not upload while printing. After an HTTP response, refresh M20 and verify the file; do not assume transfer completion.
